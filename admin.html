Admin Login

The admin panel runs on the PHP version of InkTale

This page is the static build, hosted on GitHub Pages, which cannot run PHP. The admin panel — with login, add, edit and delete for the catalogue — is part of the server build in the /server folder of the repository.

Running it locally

  1. Copy the repository into your XAMPP htdocs folder
  2. Import server/database/inktale_simple_db.sql in phpMyAdmin
  3. Copy server/config.example.php to server/config.php
  4. Open http://localhost/InkTale/server/admin_login.php
